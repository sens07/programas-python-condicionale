 Descripción

Este repositorio contiene cinco programas desarrollados en Python utilizando
estructuras condicionales `if`, `elif` y `else`.

 1. Clasificación de triángulos

Solicita las longitudes de los tres lados de un triángulo y determina si es
equilátero, isósceles o escaleno.

 2. Año bisiesto

Solicita un año al usuario y determina si es bisiesto de acuerdo con las
reglas de divisibilidad entre 4, 100 y 400.

 3. Conversor de calificaciones

Solicita una calificación numérica entre 0 y 100 y muestra su equivalencia
en letra: A, B, C, D o F.

4. Comparación de tres números

Solicita tres números y determina cuál es el mayor y cuál es el menor.

5. Tarifa de entrada

Solicita la edad de una persona y determina el costo de entrada al parque
de acuerdo con su rango de edad.
